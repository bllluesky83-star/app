# 회식 장소 추천기 (MVP)

조건(지역·날짜·인원·장르·공간·주차)을 넣고, 지도에서 찾은 후보를 직접 적으면 베이지안 점수로 Top 5를 정리해 주는 정적 웹앱입니다. **지도 API 키가 필요 없어서** 배포한 주소로 누구나 바로 쓸 수 있습니다.

## PRD와 달라진 점 (구글 API → 직접 입력)

구글과 카카오 API 키 없이 쓰기로 해서, 후보를 자동으로 검색하지 않고 사용자가 직접 입력합니다.

| PRD | 현재 |
|---|---|
| 구글 Places로 후보 자동 검색 | 순위 화면의 **네이버지도·카카오맵·구글맵 검색 링크**로 찾은 뒤 **후보 추가**로 직접 입력 (이름, 별점, 리뷰 수, 전화, 주소, 지도 링크) |
| 베이지안 평균, C = 후보 평균 별점 | 그대로. 단, 별점 있는 후보가 **5곳 미만이면 C = 4.0** (후보가 적으면 평균이 한두 곳에 휘둘리기 때문) |
| 구글 영업시간으로 휴무 자동 판정 | 세부 화면에서 **정기 휴무 요일을 직접 체크** → 취소선 반영 |
| 구글 야장·주차·예약 정보 | 모두 직접 체크 (없으면 "확인필요") |
| 날씨 좌표 = 후보 중심 | **Nominatim(오픈스트리트맵, 키 불필요)**으로 지역 이름의 위치를 찾아 사용 |
| 장기 저장은 place_id + 직접 입력값 | 후보 정보 전체가 직접 입력값이라 `places`에 저장 |

- 후보는 **지역 + 장르**로 묶여 다음 검색 때 다시 나옵니다. 그래서 같은 지역을 다시 검색하면 "지난 회식" 배지와 체크해 둔 정보가 그대로 보입니다.
- 별점·리뷰 수가 없는 후보는 순위에서 빠지고 "나머지 후보"에 나옵니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀 |
| `styles.css` | 반응형 스타일 (휴대폰 우선, 다크 모드 지원) |
| `config.js` | 설정값 (BAYES_M, BAYES_C_*, RAIN_PROB_THRESHOLD, DINNER_HOURS, TOP_N) |
| `js/app.js` | 입력·순위·후보 추가/수정·세부 화면, 점수 계산, 날씨, 저장소 |
| `serve.ps1` | 로컬 미리보기 서버 (Node/Python 불필요) |

## 로컬에서 실행

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 http://localhost:5173 을 엽니다. `http://localhost:5173/?rain=70` 처럼 열면 강수확률을 강제로 지정해 비 예보 취소선을 시험할 수 있습니다.

## 배포 (예: Netlify / Vercel / GitHub Pages)

폴더 전체를 정적 사이트로 올리면 됩니다. 빌드 명령도 키 설정도 필요 없습니다. `serve.ps1`, `README.md`, PRD 파일은 올려도 무방합니다.

## 동작 규칙 요약

- 검색 링크 검색어: `"{지역} {장르} 맛집"`, 장르가 전체면 `"{지역} 맛집"`
- 종합점수 = (v×R + m×C) ÷ (v+m), m = `BAYES_M`(50)
- 취소선(순위에는 포함):
  - 직접 체크한 정기 휴무 요일 = 회식 요일
  - 비 예보 + 공간 "야장" + 직접 "야장 있음"으로 체크한 가게
  - 직접 "없음/불가"로 체크한 룸·야장·주차가 입력 조건과 맞지 않음
- 비 예보: 회식 날짜 18~22시 강수확률 최대값 ≥ 60%. 예보 범위(오늘~16일) 밖이면 "예보 없음"
- 저장(`localStorage`, 기기별, 동기화 없음): `places`(후보), `placeNotes`(직접 확인 정보, 휴무 요일 `closedDays`), `history`(회식 기록), `lastInput`, `geoCache`(지역 위치)
